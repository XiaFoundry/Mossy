# Mossy · 攒钱小助手

> 以目标和视觉进度反馈为核心的个人攒钱工具
> **简洁 · 直观 · 本地优先 · 不接触资金**

Mossy 帮助你设定储蓄目标、记录攒钱金额，并通过环状进度图直观展示完成情况。所有数据仅保存在本机，不要求账号、不上传服务器、不依赖网络，也不会接触你的资金——实际攒钱完全由你自行完成。

## 核心功能

### 🎯 首页 · 全目标聚合环状图
- 环状进度图展示**全部目标**的聚合状态：已攒总额 / 目标总额 / 聚合百分比
- 圆环颜色随完成比例连续渐变（红橙 → 金黄 → 青绿 → 完成绿），插值在 OKLab 感知均匀空间进行，无亮度跳变
- 进度变化平滑动画，100% 附带轻量完成反馈；超额完成时圆环封顶并提示超额金额
- 本月攒钱 / 累计攒钱统计卡

### 🪙 记录攒钱 · 灵活分配
- 默认**单目标**记录，自动选中已攒金额最多的目标，可下拉切换
- 一键切换**分配到多个目标**：勾选目标后默认平均分配（余数给第一个），可手动调整，分配之和不可超出本次总额
- 快捷候选：¥10 / ¥20 / ¥50 / ¥100
- 金额校验：必须大于零、最多两位小数、禁止负数与非法字符；支持补记过去日期（禁止未来日期）

### 📁 目标管理
- 创建 / 编辑 / 暂停 / 恢复 / 归档 / 删除，截止日期为可选信息
- 目标卡片状态色点随进度从红色渐变到绿色
- 已归档目标收纳进「归档」折叠区，支持一键取消归档
- 删除目标强确认，明确提示流水将一并删除

### 📜 历史记录 · 批次与详情
- 一次分配产生的多条记录作为**整体卡片**展示，点击展开查看每条明细（年月日、时分、目标、数额、备注）
- 每条记录可进入**详情页**，右上角编辑图标即可修改或删除
- 按目标筛选，按日期倒序排列

### 🏆 成就系统（12 项）
- 里程碑成就：首次登陆、攒钱 10 / 50 / 100 / 1000 / 5000 元
- 坚持成就：连续登录 3 / 7 / 30 天
- 目标成就：完成 1 / 3 / 10 个目标
- 达成时全屏弹窗 + 彩条粒子动画，多成就排队展示；设置中可查看全部成就与解锁日期

### 🎨 多主题色板
- 浅色 / 深色 / 跟随系统三种亮暗模式
- 主题色：**跟随系统**（Android 12+ 壁纸动态取色）、经典青绿、粉色、薄荷绿、水蓝色、浅紫罗兰、黑白色
- 每套色板均包含完整明暗方案，切换即时生效

### 💾 本地数据与备份
- 一键导出 JSON 备份 / 导入恢复（导入前校验格式、版本、金额、ID 唯一性与关联关系，覆盖前二次确认）
- 清除数据、隐私说明与版本信息

### ⏰ 每日提醒（可选）
- 本地定时提醒记录攒钱，不依赖网络；通知权限被拒绝不影响核心功能

## 产品原则

- **不接触资金**：无支付、转账、跳转微信、银行绑定等功能
- **本地优先**：无账号、无服务器、无网络依赖
- **数据可靠**：所有累计金额以实际保存的流水为依据，统一业务逻辑计算
- **不制造焦虑**：无每日任务、无推荐金额施压

## 技术栈

| 类别 | 技术 |
|------|------|
| 语言 | Kotlin 2.0 |
| UI | Jetpack Compose + Material 3 |
| 架构 | UI 层 / 业务层 / 数据层，ViewModel + StateFlow |
| 数据 | Room（整数分存储、真迁移）+ DataStore |
| 异步 | Kotlin Coroutines + Flow |
| 主题 | OKLab 感知均匀插值 + Material You 动态色 |
| 测试 | JUnit 单元测试（金额 / 进度 / 建议 / 分配 / 成就 / 批次分组） |

## 构建运行

1. 安装 [Android Studio](https://developer.android.com/studio)（含 JDK 17 与 Android SDK 35）
2. 克隆仓库：
   ```bash
   git clone https://github.com/XiaFoundry/Mossy.git
   ```
3. 用 Android Studio 打开项目，等待 Gradle Sync 完成
4. 运行 `app` 到模拟器或真机（Android 8.0 / API 26+）

命令行构建：

```bash
./gradlew :app:assembleDebug      # 构建 Debug APK
./gradlew :app:testDebugUnitTest  # 运行单元测试
```
