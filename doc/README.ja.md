# Mossy · 貯金アシスタント 🌱

[English](README.en.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · **日本語** · [한국어](README.ko.md)

**シンプルで軽快、プライバシーを重視した Android 向けの貯金ツール。**

Mossy は貯金目標を設定し、貯金のたびに記録し、直感的なリング型の進捗表示で目標が少しずつ形になっていく様子を見守ります。

アカウント登録も、銀行カードの登録も、サーバー接続も不要です。記録するのはあなた自身。貯金のペースはあなた次第です。



## ✨ 機能

- **🎯 目標の可視化** — リング型の進捗表示で貯金全体の進み具合を確認でき、積み重ねが記録として残ります。
- **🪙 柔軟な記録** — 単一の目標への貯金と複数目標への分配に対応。過去の日付での記録もいつでも可能です。
- **📊 わかりやすい履歴** — 貯金の履歴をバッチ単位で表示し、1 件ずつ追跡できます。
- **🏆 軽やかな実績** — マイルストーンと連続利用の記録が、長く続ける楽しみを添えます。
- **🎨 個性的なテーマ** — ライト／ダークモード、複数のカラーパレット、Android 12+ のダイナミックカラーに対応。
- **💾 データはあなたのもの** — 端末内に保存し、JSON でのバックアップと復元が可能です。
- **⏰ 任意のリマインダー** — ローカル通知で記録を促します。サーバーは使いません。



## 🔒 プライバシー優先

Mossy はシンプルな原則に従います。**お金はあなたのもの、データもあなたのもの。**

- アカウントもログインも不要
- 銀行口座の連携なし、資金には一切触れません
- データは端末内に保存され、リモートサーバーに依存しません
- いつでも自分でエクスポート・復元できます

Mossy は貯金の記録ツールであり、銀行・決済サービス・金融プラットフォームではありません。



## 🚀 はじめかた

### 動作環境

- Android 8.0（API 26）以上



### ソースからビルド

[Android Studio](https://developer.android.com/studio) をインストールし、JDK 17 と Android SDK を設定してください。

```
git clone https://github.com/XiaFoundry/Mossy.git
cd Mossy
./gradlew :app:assembleDebug
```

生成されるデバッグ APK の場所：

```
app/build/outputs/apk/debug/app-debug.apk
```

ユニットテストの実行：

```
./gradlew :app:testDebugUnitTest
```

Android Studio でプロジェクトを開き、Gradle の同期が完了してから `app` を実行することもできます。



## 🛠️ 技術スタック

Kotlin · Jetpack Compose · Material 3 · Room · DataStore · Coroutines · StateFlow

レイヤードアーキテクチャを採用し、金額は整数の「分」で保存。主要なビジネスロジックはユニットテストでカバーしています。
