# Mossy · 저축 도우미 🌱

[English](README.en.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · **한국어**

**간단하고 깔끔하며 개인정보를 중시하는 Android 저축 도구.**

Mossy는 저축 목표를 세우고, 저축할 때마다 기록하며, 직관적인 링 형태의 진행 표시로 목표가 하나씩 이루어지는 과정을 지켜볼 수 있게 해 줍니다.

계정 가입도, 은행 카드 연동도, 서버 연결도 필요 없습니다. 기록만 하면 됩니다. 저축의 속도는 전적으로 당신의 몫입니다.



## ✨ 기능

- **🎯 목표 시각화** — 링 형태의 진행 표시로 전체 저축 현황을 확인하고, 쌓여 가는 과정을 기록으로 남깁니다.
- **🪙 유연한 기록** — 단일 목표 저축과 여러 목표 분배를 모두 지원하며, 과거 날짜로도 언제든 기록할 수 있습니다.
- **📊 명확한 기록** — 저축 내역을 배치 단위로 보고, 각 기록을 하나씩 추적할 수 있습니다.
- **🏆 가벼운 업적** — 마일스톤과 연속 사용 기록이 오래 이어 가는 즐거움을 더합니다.
- **🎨 개성 있는 테마** — 라이트/다크 모드, 다양한 색상 팔레트, Android 12+ 다이내믹 컬러를 지원합니다.
- **💾 내 데이터는 내 것** — 기기에 저장되며 JSON 백업과 복원을 지원합니다.
- **⏰ 선택형 알림** — 로컬 알림으로 기록을 알려 주며, 서버를 사용하지 않습니다.



## 🔒 개인정보 우선

Mossy는 단순한 원칙을 따릅니다. **돈도 당신의 것, 데이터도 당신의 것입니다.**

- 계정이나 로그인 불필요
- 은행 계좌 연동 없음, 자금을 처리하지 않음
- 데이터는 기기에 저장되며 원격 서버에 의존하지 않음
- 언제든 직접 내보내기와 복원 가능

Mossy는 저축 기록 도구이며, 은행이나 결제 서비스, 금융 플랫폼이 아닙니다.



## 🚀 시작하기

### 환경 요구 사항

- Android 8.0(API 26) 이상



### 소스에서 빌드

[Android Studio](https://developer.android.com/studio)를 설치하고 JDK 17과 Android SDK를 설정하세요.

```
git clone https://github.com/XiaFoundry/Mossy.git
cd Mossy
./gradlew :app:assembleDebug
```

생성되는 디버그 APK 위치:

```
app/build/outputs/apk/debug/app-debug.apk
```

단위 테스트 실행:

```
./gradlew :app:testDebugUnitTest
```

Android Studio에서 프로젝트를 열고 Gradle 동기화가 끝난 뒤 `app`을 실행해도 됩니다.



## 🛠️ 기술 스택

Kotlin · Jetpack Compose · Material 3 · Room · DataStore · Coroutines · StateFlow

계층형 아키텍처를 사용하며, 금액은 정수 '전(cents)' 단위로 저장하고 핵심 비즈니스 로직은 단위 테스트로 검증합니다.
